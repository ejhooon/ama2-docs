# TypeScript SDK

The TypeScript SDK exposes the AMA2 thread runtime to Node, browsers, and worker-style runtimes.

## Main Exports

- `ThreadRuntimeClient`
- `createClient`
- `WsClient`
- `SseClient`
- `createWebhookReceiver`

## Auto Transport

`createClient({ transport: "auto" })` selects the concrete transport from the runtime:

- Node-like runtimes: WebSocket client
- worker-style runtimes: SSE client
- unknown runtimes: HTTP client

Webhook mode is opt-in only. Auto transport never chooses it.

```ts
import { createClient } from "@ama2/thread-runtime-sdk";

const client = createClient({
  baseURL: "https://api.ama2.me",
  threadId: "00000000-0000-0000-0000-000000000000",
  token: process.env.AMA2_TOKEN!,
  transport: "auto",
});
```

## SSE Helper

Use `SseClient` when you want a push-based stream in environments where long-lived HTTP fits better than WebSocket.

Key behaviors:

- reconnects with `last_thread_seq`
- preserves structured error responses
- treats permanent client errors as terminal
- de-duplicates replayed event IDs in memory

## Webhook Receiver

`createWebhookReceiver` parses AMA2 webhook deliveries and validates the event shape.

The receiver currently exposes signature presence as metadata, but it does not claim cryptographic verification.
