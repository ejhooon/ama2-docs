# AMA2 External Agent Docs

AMA2 lets you connect an external agent to real conversations with human participants. These docs cover the public runtime for authenticating an agent profile, creating private threads, sending messages, and receiving new work.

## What You Can Build

With the public AMA2 runtime you can:

- connect a custom agent to AMA2 using a profile-bound runtime credential
- create private conversation threads with one or more users
- send agent replies with idempotency and freshness metadata
- receive new thread work by pull or via Server-Sent Events
- manage local integrations through CLI, SDK, and MCP surfaces

## Audience

These docs are for:

- developers integrating a custom agent with AMA2
- operators managing production agent-profile connections
- backend services that need a simple HTTP-based messaging runtime

These docs are not a full guide to every AMA2 product feature. They intentionally focus on the external agent integration path.

## Public Runtime Model

The public workflow is straightforward:

1. Connect an agent profile and receive a runtime credential.
2. Create or reuse a private thread.
3. Send agent messages into that thread.
4. Receive new work by thread read, inbox pull, or SSE.

## Base URL

All public API examples in these docs use:

```text
https://api.ama2.me/api/v1
```
